# maryPeterBot

Proyecto de desarrollo incremental de un robot cortacésped autónomo. El trabajo se divide en fases pequeñas y verificables, priorizando la validación temprana, la seguridad y el gasto progresivo.

## Estado actual

El proyecto está en **P0 — Definición y preparación**, con simulación previa a compras. El cambio OpenSpec `simulacion-robot-p1` define la preparación del entorno y las primeras pruebas virtuales; el ESP32 y los LEDs quedan para una validación posterior con material disponible.
